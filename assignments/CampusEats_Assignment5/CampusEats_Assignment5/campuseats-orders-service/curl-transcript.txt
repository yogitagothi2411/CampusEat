CampusEats Orders Service – Assignment 5
HTTP Methods & Headers – curl -v evidence

Demo token: campuseats-demo-token
Base URL: http://localhost:5000

NOTE: The blocks below are the reproducible curl -v commands and representative successful/failure output required by the assignment. Run them against the local service to capture live timestamps and IDs.

1) CREATE – 201 Created + Location
===================================
$ curl -v -X POST http://localhost:5000/orders ^
  -H "Authorization: Bearer campuseats-demo-token" ^
  -H "Content-Type: application/json" ^
  -H "Accept: application/json" ^
  -H "Idempotency-Key: demo-001" ^
  -d "{\"studentId\":\"STU-778812\",\"items\":[{\"itemId\":101,\"quantity\":2}],\"addressId\":10,\"paymentMethod\":\"CARD\"}"

> POST /orders HTTP/1.1
> Host: localhost:5000
> Authorization: Bearer campuseats-demo-token
> Content-Type: application/json
> Accept: application/json
> Idempotency-Key: demo-001
>
< HTTP/1.1 201 Created
< Location: /orders/1
< Content-Type: application/json
< X-RateLimit-Limit: 60
< X-RateLimit-Remaining: 59
< X-Content-Type-Options: nosniff
< Strict-Transport-Security: max-age=31536000; includeSubDomains
<
{ "orderId": 1, "status": "PLACED", "total": 240.0, ... }

11) 429 Too Many Requests
=========================
Set RATE_LIMIT=2, then send three authenticated requests within one minute.

Expected third response:
< HTTP/1.1 429 Too Many Requests
< Retry-After: <seconds>
< X-RateLimit-Limit: 2
< X-RateLimit-Remaining: 0

12) X-HTTP-Method-Override compatibility fallback
=================================================
$ curl -v -X POST http://localhost:5000/orders ^
  -H "Authorization: Bearer campuseats-demo-token" ^
  -H "X-HTTP-Method-Override: GET" ^
  -H "Accept: application/json"

The middleware converts the POST tunnel to GET before routing.
